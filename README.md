# AI Code Reviewer

AI Code Reviewer is an AI-powered web application that analyzes source code and provides feedback and improvement suggestions using the Google Gemini API.

---

## Features

* AI-powered code review
* Code improvement suggestions
* LLM-based code analysis
* Simple and interactive UI
* Full-stack application

---

## Installation

```bash
git clone https://github.com/Pruthvi1521/AI-CodeReviewer.git
cd AI-CodeReviewer
```

### Backend

```bash
cd Backend
npm install
npm start
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

---

## Project Structure

```text
Backend/   → Backend API and server logic
Frontend/  → React frontend and UI
```

---

## Workflow

1. User submits source code
2. Frontend sends the code to the backend
3. Backend sends the code to the Gemini API
4. Gemini analyzes the code
5. Review and suggestions are displayed to the user

---

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Google Gemini API
